# Кремль:2K

Первая версия-переход из архива в рабочее Next.js-приложение. Статус игры: **Пре-Альфа**.

## Запуск

```bash
npm install
npm run dev
```

Игра запускается в браузере и автоматически сохраняет кампанию в `localStorage`; PostgreSQL для игрового процесса не требуется. Проверки проекта:

```bash
npm run lint
npm run typecheck
npm run build
```

## Что добавлено в первом обновлении

- Датированная историческая очередь из 212 событий; случайные шаблонные события отключены.
- Вертикальная компоновка деревьев решений, графика распределения 450 мест Госдумы и переименование партии.
- Идеологии «Политический ислам» и «Социализм».
- Выбор игрового персонажа или создание партийца с позициями, фракционной симпатией и особенностями.
- Вкладки «Войны», «Конфликты» и «Внешняя политика»; 18 сценариев с выбором стороны, фракции и лидера, расходованием ресурсов и изменением правительства/идеологии страны.
- Интерактивная карта с 253 странами и территориями, флагами и окном дипломатии.
- Удалён счётчик пройденных событий; версия «Пре-Альфа» показана в интерфейсе.

Геометрия карты упрощена из Natural Earth / `world-atlas`; имена и флаги стран основаны на `world-countries`. В кампанийных сценариях альтернативные исходы явно помечены, чтобы отличать их от документированной исторической линии.
